# Publishing qbcheck to the Google Workspace Marketplace (unlisted)

This is a copy-paste reference and step-by-step workflow for publishing the
qbcheck **Google Docs editor add-on** to the Google Workspace Marketplace as an
**unlisted** add-on. The build outputs live in `apps-script/` (`Code.js`,
`Sidebar.html`, `appsscript.json`), regenerated by `npm run build:apps-script`.

> Everything in this file except the "Listing copy" and "Scope justifications"
> sections is a manual task performed in the Apps Script editor and the Google
> Cloud console — there is nothing further to change in the repo.

---

## 1. Listing copy (paste into the Marketplace SDK store listing)

**Application name:** qbcheck

**Short description** (≤ ~120 chars):

> Lint quizbowl question packets for QMOS style and formatting compliance,
> directly in Google Docs.

**Detailed description:**

> qbcheck checks quizbowl question packets for style and formatting issues based
> on QMOS conventions, without leaving Google Docs.
>
> - Lint the whole packet, or just the question your cursor is in.
> - 60+ rules across packet structure, question text, answer lines,
>   pronunciation guides, formatting/typography, tags, and writing style.
> - Auto-fix common issues in place with one click.
> - Click any issue to jump to its question in the document.
> - Turn individual rules on or off to match your tournament's style.
>
> Runs entirely within Google's Apps Script environment on the open document
> only — no document content leaves Google, and nothing is sent to third
> parties. See the privacy policy for details.

**Single-purpose statement:**

> qbcheck lints quizbowl question packets for QMOS style and formatting
> compliance inside Google Docs.

**Category:** Productivity (alternatively Education).

## 2. OAuth scopes and justifications (for the consent screen)

The add-on requests two scopes, both declared in `apps-script/appsscript.json`:

| Scope | Justification |
| ----- | ------------- |
| `https://www.googleapis.com/auth/documents.currentonly` | Read the currently open packet to run style checks, and apply auto-fixes in place when the user chooses to. Access is limited to the open document only. |
| `https://www.googleapis.com/auth/script.container.ui` | Display the qbcheck sidebar UI inside Google Docs. |

Both scopes are **non-sensitive**, so this add-on is not expected to require the
restricted-scope OAuth security assessment. Publishing as **unlisted** also keeps
the review lightweight. Do not add broader scopes (e.g. full `documents` or
`drive`) — they would trigger sensitive/restricted review.

## 4. Console workflow (manual)

### a. Create the Apps Script project

1. Go to <https://script.google.com>, create a **new standalone project** named
   "qbcheck".
2. Enable **Project Settings → "Show 'appsscript.json' manifest file in editor"**.
3. Replace the project's files with the build outputs:
   - Paste `apps-script/Code.js` into the `Code.gs` file.
   - Create an HTML file named `Sidebar` and paste in `apps-script/Sidebar.html`.
   - Paste `apps-script/appsscript.json` into the manifest.
4. Reload a Google Doc and confirm **Extensions → qbcheck → Open sidebar** works
   (via a test deployment — see step d).

### b. Attach a standard Google Cloud project (required for Marketplace)

1. In <https://console.cloud.google.com>, create (or choose) a **standard GCP
   project** and note its **project number**.
2. In the Apps Script project: **Project Settings → Google Cloud Platform (GCP)
   Project → Change project** and enter the project number.

### c. Configure the OAuth consent screen

In the GCP project, open **APIs & Services → OAuth consent screen** and set:

- App name: **qbcheck**, user support email, developer contact email.
- App logo (128×128).
- Add the two scopes from section 2.
- Set the publishing/user type appropriate for an unlisted add-on.

### d. Create a versioned deployment

In the Apps Script editor: **Deploy → New deployment → Add-on**, create a
versioned deployment, and note the **Deployment ID**. (Use **Deploy → Test
deployments** for pre-publish smoke testing.)

### e. Configure the Google Workspace Marketplace SDK

In the GCP project, **APIs & Services → Library**, enable **Google Workspace
Marketplace SDK**, then under its configuration:

1. **App Configuration:**
   - App visibility: **Unlisted**.
   - Integrate with **Google Docs** as an **editor add-on**.
   - Point at the Apps Script **deployment** from step d.
2. **Store Listing:**
   - Paste the listing copy (section 1) and scope justifications (section 2).
   - Upload the icon and screenshot(s) (section 3).
   - Set the privacy policy, terms, and support URLs (section 1).
3. Save and **Publish** — with visibility Unlisted, the add-on is installable via
   its share link but does not appear in Marketplace search.

---

## 5. After publishing

- Install via the unlisted share link and verify the add-on installs, the menu
  appears immediately (thanks to `onInstall`), and linting/fixing works.
- To ship an update: rebuild (`npm run build:apps-script`), paste the refreshed
  outputs into the Apps Script project, create a **new versioned deployment**,
  and point the Marketplace SDK App Configuration at it.
